* Technique 1: Histogram Analysis
:PROPERTIES:
:CUSTOM_ID: histogram
:END:

The histogram shows the distribution of pixel intensities. Manipulated
images often have unnatural histograms - gaps, spikes, or unusual patterns.

#+BEGIN_SRC python
def plot_rgb_histogram(image, title="RGB Histogram"):
    """Plot separate histograms for R, G, B channels."""
    fig, axes = plt.subplots(1, 2, figsize=(14, 4))

    # Show image
    axes[0].imshow(image)
    axes[0].set_title("Image")
    axes[0].axis('off')

    # Plot histograms
    colors = ['red', 'green', 'blue']
    for i, c in enumerate(colors):
        hist, bins = exposure.histogram(image[:,:,i])
        axes[1].plot(bins, hist, color=c, alpha=0.7, label=c.upper())

    axes[1].set_xlabel("Pixel Value")
    axes[1].set_ylabel("Frequency")
    axes[1].set_title(title)
    axes[1].legend()
    axes[1].set_xlim(0, 255)

    plt.tight_layout()
    plt.show()

plot_rgb_histogram(image, "Original Image Histogram")
#+END_SRC

* Technique 2: Error Level Analysis (ELA)
:PROPERTIES:
:CUSTOM_ID: ela
:END:

ELA reveals areas that have been resaved at different quality levels.
When part of an image is pasted from another source, it often has
a different compression history.

#+BEGIN_SRC python
from skimage import io
from skimage.metrics import structural_similarity as ssim
import tempfile
import os

def error_level_analysis(image, quality=90):
    """
    Perform Error Level Analysis.

    Resave image at lower quality, then compare to original.
    Areas with different compression history will show up.
    """
    # Save at specified quality and reload
    with tempfile.NamedTemporaryFile(suffix='.jpg', delete=False) as f:
        temp_path = f.name

    # We'll simulate this by applying JPEG-like quantization
    # (Real ELA would use actual JPEG compression)

    # Simulate compression artifacts
    from skimage.transform import resize
    small = resize(image, (image.shape[0]//8, image.shape[1]//8),
                   anti_aliasing=True)
    resaved = resize(small, image.shape[:2], anti_aliasing=True)

    # Compute difference and amplify
    diff = np.abs(image.astype(float)/255 - resaved)
    ela = diff * 10  # Amplify differences
    ela = np.clip(ela, 0, 1)

    return ela

ela_result = error_level_analysis(image)

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

axes[0].imshow(image)
axes[0].set_title("Original")

axes[1].imshow(ela_result)
axes[1].set_title("Error Level Analysis")

# Convert to heatmap
ela_gray = color.rgb2gray(ela_result)
axes[2].imshow(ela_gray, cmap='hot')
axes[2].set_title("ELA Heatmap")

for ax in axes:
    ax.axis('off')
plt.tight_layout()
plt.show()

Uniform ELA = consistent compression history (likely authentic).
Patchy ELA = different areas compressed differently (possible edit).

* Technique 3: Noise Analysis
:PROPERTIES:
:CUSTOM_ID: noise
:END:

Every camera sensor produces characteristic noise patterns. If part
of an image has different noise characteristics, it may be composited.

#+BEGIN_SRC python
def analyze_noise(image, block_size=32):
    """
    Analyze local noise levels across the image.
    Returns a map of noise variance per block.
    """
    gray = color.rgb2gray(image)

    # Calculate local variance using a sliding window approach
    from scipy.ndimage import uniform_filter

    # Local mean
    local_mean = uniform_filter(gray, size=block_size)

    # Local variance
    local_sqr_mean = uniform_filter(gray**2, size=block_size)
    local_var = local_sqr_mean - local_mean**2

    return local_var

noise_map = analyze_noise(image)

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

axes[0].imshow(image)
axes[0].set_title("Original Image")

axes[1].imshow(noise_map, cmap='viridis')
axes[1].set_title("Noise Variance Map")
axes[1].colorbar = plt.colorbar(axes[1].images[0], ax=axes[1])

# Threshold to highlight anomalies
threshold = np.percentile(noise_map, 95)
anomalies = noise_map > threshold
axes[2].imshow(anomalies, cmap='Reds')
axes[2].set_title("High-Variance Regions")

for ax in axes:

plt.tight_layout()

* Technique 4: Frequency Domain Analysis
:PROPERTIES:
:CUSTOM_ID: frequency
:END:

The Fourier transform reveals periodic patterns invisible to the eye.
JPEG artifacts, resampling, and certain manipulations leave telltale
signatures in the frequency domain.

#+BEGIN_SRC python
def frequency_analysis(image):
    """Compute and visualize the 2D Fourier transform."""
    gray = color.rgb2gray(image)

    # 2D FFT
    f_transform = fftpack.fft2(gray)
    f_shift = fftpack.fftshift(f_transform)  # Center the zero frequency

    # Magnitude spectrum (log scale for visibility)
    magnitude = np.log1p(np.abs(f_shift))

    # Phase spectrum
    phase = np.angle(f_shift)

    return magnitude, phase

mag, phase = frequency_analysis(image)

fig, axes = plt.subplots(1, 3, figsize=(15, 5))

axes[0].imshow(gray, cmap='gray')
axes[0].set_title("Grayscale Image")

axes[1].imshow(mag, cmap='magma')
axes[1].set_title("Frequency Magnitude (log)")

axes[2].imshow(phase, cmap='twilight')
axes[2].set_title("Frequency Phase")

for ax in axes:
    ax.axis('off')
plt.tight_layout()
plt.show()
#+END_SRC

The bright cross pattern in the magnitude is normal (image edges).
Look for unusual spikes or grid patterns - these indicate resampling
or periodic artifacts from editing.

* Technique 5: Edge Inconsistency Detection
:PROPERTIES:
:CUSTOM_ID: edges
:END:

Natural photographs have consistent edge characteristics throughout.
Composited images often have sharper or blurrier edges where elements
were pasted in.

#+BEGIN_SRC python
def edge_consistency_map(image, sigma=2):
    """
    Map edge strength across the image.
    Inconsistencies may indicate compositing.
    """
    gray = color.rgb2gray(image)

    # Multi-scale edge detection
    edges_fine = feature.canny(gray, sigma=1)
    edges_medium = feature.canny(gray, sigma=2)
    edges_coarse = feature.canny(gray, sigma=4)

    # Edge density (how many edges in local region)
    from scipy.ndimage import uniform_filter

    density_fine = uniform_filter(edges_fine.astype(float), size=20)
    density_medium = uniform_filter(edges_medium.astype(float), size=20)
    density_coarse = uniform_filter(edges_coarse.astype(float), size=20)

    # Ratio between scales - should be consistent for natural images
    ratio = np.divide(density_fine, density_coarse + 0.001)

    return ratio, edges_fine, edges_medium, edges_coarse

ratio, e1, e2, e3 = edge_consistency_map(image)

fig, axes = plt.subplots(2, 3, figsize=(15, 10))

axes[0, 0].imshow(image)
axes[0, 0].set_title("Original")

axes[0, 1].imshow(e1, cmap='gray')
axes[0, 1].set_title("Fine Edges (σ=1)")

axes[0, 2].imshow(e3, cmap='gray')
axes[0, 2].set_title("Coarse Edges (σ=4)")

axes[1, 0].imshow(e2, cmap='gray')
axes[1, 0].set_title("Medium Edges (σ=2)")

axes[1, 1].imshow(ratio, cmap='RdYlBu')
axes[1, 1].set_title("Fine/Coarse Edge Ratio")

# Highlight suspicious regions (unusual ratios)

axes[1, 2].imshow(suspicious, cmap='Reds')

#+BEGIN_SRC python
def forensic_analysis(image, title="Image"):
    """
    Perform comprehensive forensic analysis on an image.
    """
    fig = plt.figure(figsize=(16, 12))

    # Original
    ax1 = fig.add_subplot(3, 4, 1)
    ax1.imshow(image)
    ax1.set_title(f"{title}")
    ax1.axis('off')

    # Histogram
    ax2 = fig.add_subplot(3, 4, 2)
    for i, c in enumerate(['r', 'g', 'b']):
        hist, bins = exposure.histogram(image[:,:,i])
        ax2.plot(bins, hist, color=c, alpha=0.7)
    ax2.set_title("Color Histogram")
    ax2.set_xlim(0, 255)

    # ELA
    ax3 = fig.add_subplot(3, 4, 3)
    ela = error_level_analysis(image)
    ax3.imshow(ela)
    ax3.set_title("Error Level Analysis")
    ax3.axis('off')

    # Noise map
    ax4 = fig.add_subplot(3, 4, 4)
    noise = analyze_noise(image)
    ax4.imshow(noise, cmap='viridis')
    ax4.set_title("Noise Variance")
    ax4.axis('off')

    # Frequency magnitude
    ax5 = fig.add_subplot(3, 4, 5)
    mag, _ = frequency_analysis(image)
    ax5.imshow(mag, cmap='magma')
    ax5.set_title("Frequency Spectrum")
    ax5.axis('off')

    # Edge analysis
    gray = color.rgb2gray(image)

    ax6 = fig.add_subplot(3, 4, 6)
    edges = feature.canny(gray, sigma=2)
    ax6.imshow(edges, cmap='gray')
    ax6.set_title("Edge Detection")
    ax6.axis('off')

    # Gradient magnitude
    ax7 = fig.add_subplot(3, 4, 7)
    gradient = filters.sobel(gray)
    ax7.imshow(gradient, cmap='gray')
    ax7.set_title("Gradient Magnitude")
    ax7.axis('off')

    # Local entropy (texture complexity)
    ax8 = fig.add_subplot(3, 4, 8)
    from skimage.filters.rank import entropy
    from skimage.morphology import disk
    entropy_img = entropy(
        (gray * 255).astype(np.uint8),
        disk(5)
    )
    ax8.imshow(entropy_img, cmap='inferno')
    ax8.set_title("Local Entropy")
    ax8.axis('off')

    # Summary statistics
    ax9 = fig.add_subplot(3, 4, (9, 12))
    ax9.axis('off')

    stats_text = f"""
    FORENSIC ANALYSIS SUMMARY
    ─────────────────────────

    Image Size: {image.shape[1]} × {image.shape[0]} pixels
    Color Depth: {image.dtype}

    Intensity Statistics:
      Mean: R={image[:,:,0].mean():.1f} G={image[:,:,1].mean():.1f} B={image[:,:,2].mean():.1f}
      Std:  R={image[:,:,0].std():.1f} G={image[:,:,1].std():.1f} B={image[:,:,2].std():.1f}

    Edge Density: {edges.mean()*100:.2f}%
    Noise Level (avg variance): {noise.mean():.4f}

    Observations:
    • Histogram appears {'continuous' if True else 'discontinuous (possible edit)'}
    • ELA shows {'uniform' if ela.std() < 0.1 else 'non-uniform'} compression
    • Noise distribution is {'consistent' if noise.std() < noise.mean() else 'variable'}
    """

    ax9.text(0.1, 0.9, stats_text, transform=ax9.transAxes,
             fontfamily='monospace', fontsize=10,
             verticalalignment='top')

    plt.tight_layout()
    plt.show()

# Run full analysis
forensic_analysis(image, "Astronaut Test Image")

* Summary
:PROPERTIES:
:CUSTOM_ID: summary
:END:

We explored five forensic techniques:

| Technique | What It Reveals | Signs of Manipulation |
|-----------+-----------------+-----------------------|
| Histogram | Pixel distribution | Gaps, combing, spikes |
| ELA | Compression history | Patchy error levels |
| Noise | Sensor characteristics | Inconsistent noise |
| FFT | Periodic patterns | Unusual frequency spikes |
| Edges | Sharpness consistency | Variable edge quality |

These techniques are used by forensic analysts, journalists, and
researchers to verify image authenticity. While no single method is
foolproof, combining multiple approaches provides strong evidence.

Remember: absence of detection doesn't prove authenticity, and
presence of artifacts doesn't prove manipulation. Always consider
the full context!
