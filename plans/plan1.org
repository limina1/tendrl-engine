#+TITLE: Nostr Engine - Standalone Local Nostr Backend
 #+DATE: 2026-01-26

* Overview

 Create a standalone Rust project =nostr-engine= at =/home/user/Documents/Programming/nostr-engine= that acts as a local Nostr backend with HTTP API. Other apps
 (Flask/Jinja, Python scripts, any HTTP client) can use it to query and fetch Nostr events.

 ** Key Features
 - Query local nostrdb first, fetch from relays on miss
 - Configurable fetch policies (local_only, local_first, fetch_always)
 - Clean REST API for any language/framework
 - Can be used as library (Rust) or standalone service (HTTP)

 - Core Components

 ** 1. FetchPolicy Enum

 #+begin_src rust
 pub enum FetchPolicy {
     LocalOnly,    // Only query nostrdb
     LocalFirst,   // Try local, fetch if empty (default)
     FetchAlways,  // Always fetch, merge with local
 }
 #+end_src

 ** 2. Engine Struct

 #+begin_src rust
 pub struct Engine {
     ndb: Ndb,
     relays: Vec,
     timeout_ms: u64,
 }

 impl Engine {
     pub fn new(data_path: &Path) -> Result;
     pub async fn get_events(&self, filter: Value, policy: FetchPolicy) -> Result;
     pub async fn get_by_id(&self, id: &str, policy: FetchPolicy) -> Result<Option>;
     pub async fn get_addressable(&self, kind: u64, pubkey: &str, d_tag: &str, policy: FetchPolicy) -> Result<Option>;
 }
 #+end_src

 ** 3. HTTP API Endpoints

 | Method | Route                              | Description                    |
 |--------+------------------------------------+--------------------------------|
 | POST   | /api/v1/query                      | Query with NIP-01 filters      |
 | GET    | /api/v1/events/:id                 | Get event by ID                |
 | GET    | /api/v1/addressable/:kind/:pk/:d   | Get addressable event          |
 | GET    | /health                            | Health check                   |

 - Usage Examples

 ** As Standalone Service
 #+begin_src bash
 Install

 cargo install --git https://github.com/youruser/nostr-engine

 Run

 nostr-engine --port 3030 --data-dir ~/.local/share/nostr-engine

 Query from any app

 curl -X POST http://localhost:3030/api/v1/query
   -H "Content-Type: application/json"
   -d '{"filters": [{"kinds": [30040], "limit": 10}]}'
 #+end_src

 ** As Rust Library
 #+begin_src rust
 use nostr_engine::{Engine, FetchPolicy};

 let engine = Engine::new("~/.local/share/nostr-engine")?;
 let events = engine.get_events(
     json!({"kinds": [30040], "limit": 10}),
     FetchPolicy::LocalFirst
 ).await?;
 #+end_src

 ** From Python/Flask
 #+begin_src python
 import requests

 resp = requests.post("http://localhost:3030/api/v1/query", json={
     "filters": [{"kinds": [30040], "limit": 10}],
     "policy": "local_first"
 })
 events = resp.json()["events"]
 #+end_src
