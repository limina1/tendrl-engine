* (b) Theme summary

The web layer has cleanly completed its Svelte-5-runes migration and the WM/buffer
paradigm is the consistent organizing principle. The main debt is leftover from the
pre-WM three-panel workbench: five truly-dead components + three design-only components
reachable only from unlinked =/design/*= artboards, and seven dead =api.ts= functions.
The modal/view clusters that look redundant on the surface are in fact justified,
distinct lifecycle/input variants — the only real cross-component overlap is mild
(outline rendering, result-item rows) and not worth consolidating now. Highest-value
cleanup: delete the 5 orphans + 7 dead api functions + the demo seed (see [[file:06-web-wm-buffer.org][06]]), then
decide the fate of the =/design/*= scratch routes.
