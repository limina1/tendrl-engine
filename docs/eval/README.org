* Method

Audit run on branch =tendrl-web= (HEAD =c5503c0=). Construction order: build a map
from commit history + roadmap docs first, then fan out one auditor per code domain
and cross-reference each set of findings against the documented intent.

Dead-code claims in the domain docs were verified with =rg= / =grep= before
inclusion. File:line references are org links into the source tree — click to jump.
