** Common error responses

- =400 {"error":{"message":"Invalid bech32 encoding: ...","type":"invalid_filter"}}= →
  the string is corrupted or has the wrong checksum (often a paste issue).
- =400 {"error":{"message":"Unknown HRP: foo","type":"invalid_filter"}}= →
  not a NIP-19 identifier we handle (only npub / nprofile / nevent / naddr).
- =400 {"error":{"message":"Missing required TLV type 0x00","type":"invalid_filter"}}= →
  payload structurally valid bech32 but missing a required field for the
  detected variant.

** Replay handler dispatch

The =replayEntry= helper is a switch on =entry.kind=:

- =query= → =app.handleSearch(entry.query, entry.opts)=
- =nevent= → =app.getEventForModal(entry.eventId)=
- =naddr= → build =k:K by:HEX #d:D= and call =handleSearch= with
  =scopeToMe: false= (backend accepts hex in =by:= per
  =src/search.rs:471=).

The =naddr= path isn't exercised yet — those entries only get pushed
once Slice 5 wires =a=-tag clicks in the EventViewModal. Its replay
path is in place for when that lands.

* Slice 5 — Identifiers + Tags blocks in EventViewModal

The modal now has two real sections beyond the header: *Identifiers*
( =id= / =addr= / =author= rows with clickable values + copy buttons)
and *Tags* (every tag rendered as a chip with kind-tinted prefix;
clickable when the value maps to a known action).

Click dispatch:

| Tag         | Value shape       | Action                                                                |
|-------------+-------------------+-----------------------------------------------------------------------|
| =e= / =q= / =note= | hex64             | chained nav — =getEventForModal(value)= swaps the modal in place      |
| =a=         | =30040:pk:d=      | =onspawnreader(pk, d, null)=, close modal                             |
| =a=         | =K:pk:d= (K≠30040) | local_only =queryEvents=, swap modal to newest, push naddr history    |
| =p=         | hex64             | =handleSearch("by:" + encodeNpub(value))=, close modal                |
| =d=         | any text          | =handleSearch("#d:" + value)=, close modal                            |
| =t=         | any text          | =handleSearch("#t:" + value)=, close modal                            |
| 1-char key  | whitespace-free   | =handleSearch("#key:value")=, close modal                             |
| anything else                  | none — plain chip                                                     |

Hex values are validated by =/^[0-9a-f]{64}$/= (lowercased first);
non-hex falls through to plain chip. =nostr:= prefix is stripped at
the input boundary via =stripNostrPrefix=.

The =d= tag itself is hidden from the Tags block — its value is
shown as the =addr= row in Identifiers. =title= is also hidden (it's
already the modal header).

** Encoder symmetry note

The added =encodeNpub= uses =BECH32_CONST = 1=, not =BECH32M_CONST=
=0x2bc830a3=. NIP-19 splits the namespace: =npub= / =nsec= are
bech32, everything else (including =nevent= / =naddr= / =nprofile=)
is bech32m. =encodeNevent= correctly uses the bech32m constant. If a
copied =npub1...= fails to decode with the right pubkey, the
checksum constant is the first thing to suspect.
