The monolithic feature list has been reorganized into the tendrl
zettelkasten: one note per feature area, hierarchically organized through
a single index and cross-referenced with ideas, decisions, and the
software we model off of.

*Start here:* [[file:zettel/index.org][docs/zettel/index.org — The Tendrl Map]]

Feature-area notes are the =feat-*.org= files in =docs/zettel/=. Maintenance
rule ([[file:zettel/conventions.org][conventions]]): a change that ships a
user-visible feature updates the matching =feat-*= zettel in the same
commit/PR.

The previous monolithic inventory is preserved in git history
(=git log -- docs/features.org=, last full version 2026-06-22).
