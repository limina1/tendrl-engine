#+title: Icon generation — Phototropic Decay

The tendrl mark is generative: a recursive branching organism grown from a
seed, projected onto a receding plane. =phototropic-decay.html= is the lab —
open it in a browser, drag the canvas to shape the organism, and export.

* Identity

Every design has a stable identifier: =phototropic-<seed>-<hash>=, where the
hash (djb2, base36) covers every parameter that affects the rendered output.
The lab shows the current identifier live in the Export section; any slider
move changes it.

* Export / import

- *PNG + params* / *SVG + params* download the asset as =<id>.png= / =<id>.svg=
  *plus* a matching =<id>.json= carrying the full parameter set.
- *Load settings…* takes such a =.json= (the exported wrapper or a bare params
  object) and restores the design exactly — same id, same pixels.

Committed designs live in this directory as the =<id>.svg= + =<id>.json= pair,
so any of them can be reloaded into the lab and re-exported at any size.

* Making an export the Android app icon

One command — the per-release flow is: shape a design in the lab, export
*SVG + params*, drop both files here, then:

#+begin_src bash
scripts/make-android-icon.sh docs/icon-generation/phototropic-<id>.svg
git add docs/icon-generation mobile/src-tauri && git commit
#+end_src

The script rasterizes the SVG with headless Chromium (real browser engine,
so the bloom filter renders correctly), writes
=mobile/src-tauri/icons/source.png= (1024 px), runs =cargo tauri icon=
(desktop + iOS + Android mipmaps), then re-applies the adaptive-icon
layers that tauri gets wrong:

- =gen/android/…/values/ic_launcher_background.xml= is set to the design's
  =bg= param (read from the =<id>.json= beside the svg; default =#000000=;
  tauri writes =#fff=).
- The =ic_launcher_foreground.png= mipmaps are re-rendered with the mark
  fitted to the adaptive safe zone (center 72/108 of the canvas) on the
  =bg= color, so Android-8+ launchers show the whole organism instead of
  a center crop.

Committing the svg+json pair alongside the icon set keeps every release's
icon reproducible: =Load settings…= restores the design in the lab, and
re-running the script reproduces the exact installed icons.
