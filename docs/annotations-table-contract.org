* What ships (one paragraph)

Tools → *table N* on a reader opens the annotations table for that
publication: on desktop it *splits the pane* (reader | table,
=store.splitFocused=), on mobile it is the focused work buffer, listed in
the ☰ drawer. One buffer kind =annotations:<root>=, five layouts (by
section · by author · timeline · free · collective), a spell input with a
wand, author bars that filter and rewrite the spell, requests on the table
as cards with a badge, hover lights the reader section, the =§n= chip
scrolls the reader, =j=/=k=/=Enter=, drag-to-pin in free layout. Colour is
per author with the highlight recipe (=discussions/colors.ts=,
=pubkeyToColor=): card rail, author dot, anchor chip, histogram bar. The
reader gains a *notes: margin | inline* Reading preference (D9: margin on
a wide pane, inline while split or below the measure, folds on the phone)
and stops counting request-30041s as pending notes.

* Engine API (Track A)

=POST /api/v1/insertions/load= body gains:

- =since: Option<i64>= — NIP-01 since on the =#A= pass.
- =counts: bool= — when true, the =#A= pass runs *without* the author
  filter, histograms are computed over the whole root, then =retain= by
  author. Response gains =counts: { by_author, by_parent, total }= of
  =TagValueCount= (=by_author= values are hex pubkeys, =label= = kind-0
  display name via =label_author_buckets=; =by_parent= values are parent
  coordinates). Notes only: =role == Request= excluded from counts.
- Confirm-mode intent text when =counts= is set and authors are given:
  "any author (table)" — the modal must say the fetch is broader than
  the filter.

Pure =insertion_counts(&[LoadedInsertion]) -> InsertionCounts= with a
unit test; one assertion added to =test_insertion_propose_load_and_promote=.

* App state hooks (Track 0, consumed by B and C)

- =app.readerJump: { root, addr, nonce } | null=; =app.requestReaderJump(root, addr)=.
  The reader keeps a module-scope =appliedJumpNonce=; an =$effect= on
  =app.readerJump= that matches its root and a new nonce calls
  =gotoSection(i, 'teleport')= and scrolls the section into view.
- =app.hoverAnchor: { root, addr, count } | null=; =app.setHoverAnchor(v)=
  (no write when unchanged). The reader passes =hotAddr= down to the
  section views → =class:anchor-hot= + an =.anchor-tip= "N cards →".
- =reading.notesLayout: 'margin' | 'inline'=, =setReadingNotesLayout=.

** Keys (desktop, table focused)

=j=/=k= move the cursor across =placed= in layout order; =Enter= toggles
expand; =←=/=→= switch mode; =m= cycles mode; =Esc= clears expand. A
=nav= handler registered the way =RepositoryBuffer= does (=NavAction=).

* Layout rules (Track C, =layoutCards=)

- *section*: one lane per TOC row in reading order, plus a leading
  "whole publication" lane when any card anchors to the root; cards
  packed left-to-right in =floor((width - 2·PAD + GAP) / (W + GAP))=
  columns, order = requests, before, attached, after, then by time.
  Empty lanes collapse to =LANE_HEAD + 6=.
- *author*: one lane per author by descending count (=authorBars=
  order), cards by section then time.
- *timeline*: x by =createdAt= across =[min - 1h, max + 1h]=, greedy row
  assignment (first row whose right edge + GAP ≤ x), day ticks, =.m=
  cards; width grows with card count (≥ 70 px per card).
- *free*: the section layout as the base; =pins[id]= overrides x/y;
  height/width grow to contain pins.
- *collective*: rows = authors, columns = sections at =AXIS + n·(WS + GAP)=,
  a stack per cell offset 22 px; =.axis= "§n" marks along the top.
- Expanded card: =WX × HX=, z-index above siblings, no re-pack.
- The drag transient is never an input to =layoutCards=.

* View state

=AnnotationsViewState= (=table-model.ts=) read once from
=store.bufferState= on mount, written on =$effect= teardown. Loaders use
a plain =book= object (effect-loop discipline —
=project_effect_async_state_loop=): effects depend on version counters
(=app.insertionsVersion=, =app.requestsVersion=) and never read state the
loader writes. Live updates through =onStoreEvent= + =concernsRoot=,
debounced, callback not effect.
