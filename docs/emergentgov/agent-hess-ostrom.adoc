== Flags for the human

1. Exit is absent from the framework's governance vocabulary — all
   levers are voice-shaped (rule modification, participation).
   Exit-based relay discipline needs Hirschman/Tiebout imported via
   link:concept-exit-voice.adoc[concept-exit-voice] / link:concept-interjurisdictional-competition.adoc[concept-interjurisdictional-competition].
2. "Clearly defined boundaries" (Intro p. 7) should be re-specified
   as boundary-setting *capacity* under expand–contract dynamics;
   Nostr boundaries are plural, per-facility, and fluid.
3. UKAC ch. 3 note 2 (p. 68): left-side IAD variables are only
   "temporarily" exogenous, feedback loops matter in fast systems.
   On Nostr that footnote is the main case — rules reshape the
   facility set within weeks. Worth making explicit when adapting
   link:concept-iad-framework.adoc[concept-iad-framework].
4. Rules definitionally require "minimal sanctioning ability" (ch. 3
   p. 50); kind-1984's decoupled sanctions strain the ADICO "or
   else" — feed link:q-decoupled-vs-unitary-sanctions.adoc[q-decoupled-vs-unitary-sanctions].
5. Removal/deletion: the 2007 removal right is advisory on Nostr;
   the fugitive-artifact problem (2003 p. 144) inverts into a
   right-to-be-forgotten strain. No assigned q- note covers this;
   consider coining one.
6. Survivorship caveat recorded in link:concept-survivorship-bias.adoc[concept-survivorship-bias]:
   observing formation ≠ representativeness; archive Nostr's own
   failures deliberately or the bias recurs one level up.
