== Flags for Andrew

1. Veto-theorem inversion: Vincent grounds Madisonian checks in
   Ashby's veto theorem (Lewis & Aligica p. 11) — parts with veto
   power force concurrence of the whole. Nostr *inverts* this: no
   global bannability means no part has veto over the whole, and
   concurrence is unnecessary by design. The thesis should claim
   inversion, not instantiation.
2. Substrate- vs community-homeostasis: the cybernetic account
   presumes a shared setpoint; Nostr relays hold divergent targets.
   What is homeostatic is protocol interoperability, not substantive
   outcomes. Distinguish these explicitly (see
   link:concept-adaptive-governance.adoc[concept-adaptive-governance]).
3. Un-rescindable rule-history: Ostrom — "always possible to rescind
   it or reinstate it—or it is not a rule" (p. 86). On Nostr policies
   are rescindable but their signed change-history is append-only.
   The rule *artifact* outlives the rule; new territory for the
   framework.
4. Citation discipline flags recorded in link:src-digging-deeper.adoc[src-digging-deeper]: that
   chapter is NOT a source for "holons" nor for polycentricity.
5. Lateral-plural-alpha: the Nostr case suggests Ashby's meta-level
   corrector can be lateral and plural (uncoordinated parallel
   layers), not only nested — a genuine theoretical extension worth a
   `syn-` note if Andrew endorses it.
