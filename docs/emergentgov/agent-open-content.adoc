== Flags for the human

1. Observability loss from off-platform coordination: both sources
   converge on it — Schroeder's off-platform channels "limit
   involvement and reduce transparency" (1956); Modular Politics'
   civic-sphere caveat (16:20). The GitHub/Telegram layer where NIP
   debates and relay-op decisions happen is the civic sphere the
   Nostr event stream misses. The formation-observable claim needs
   this stated as a scope condition, not discovered as a rebuttal.
2. Shared/idiosyncratic filter may not transfer: Schroeder discards
   constructs not shared across editors (1952–1953). On Nostr an
   idiosyncratic mechanism (one relay's odd policy) still binds its
   subscribers; a Nostr replication should keep, not discard, the
   idiosyncratic tail.
3. Corrections carried into the notes: Modular Politics' first author
   is Schneider (not Zhang/Frey as an earlier memo guessed), and
   PolicyKit appears nowhere in that paper — cite PolicyKit
   separately if needed.
4. Provenance caveat: quotes were spot-carried from the prior
   reader's notes, not re-verified against the PDFs in this session;
   checking these two src- notes means following locators into the
   PDFs (printed = PDF + 1946 for Schroeder; identical for Schneider).
