== Flags for the human

1. No clean IAD slot for no-global-bannability: boundary/entry-exit
   rules always bound a specific situation; nothing in either source
   models a substrate on which exclusion is possible everywhere locally
   and impossible globally. Best available scaffold: McGinnis's default
   conditions (p. 10) as the un-repealable baseline.
2. Community-attributes strain: both sources make shared norms,
   homogeneity, and multiplex ties (Ostrom p. 43; McGinnis p. 12) the
   soil of rule formation; Nostr's pseudonymous open-entry population
   lacks these yet forms rules anyway. Needs explicit treatment.
3. Polycentricity definition (McGinnis p. 6) requires authorities that
   _interact_ to set each other's conditions; relay operators mostly
   don't. Either extend the concept (protocol as coordination medium)
   or coin a distinct term. Left in link:concept-polycentricity.adoc[concept-polycentricity] (dangling).
4. ADICO finding worth foregrounding: kind-1984 is a norm (ADIC), not a
   rule — the Or Else is crowdsourced. See link:concept-adico-grammar.adoc[concept-adico-grammar].
5. McGinnis's own "good practices" hedge (p. 19) plus Ostrom's p. 48
   phrasing give direct textual support for the survivorship-bias
   argument — no need to overclaim it.
6. Design principle 7 (recognition by higher authorities) has no Nostr
   referent; principle 8 (nested enterprises) may be the composability
   motif's closest ancestor.
7. Verbatim quotes were kept ≤25 words; all Ostrom locators are printed
   book pages, all McGinnis locators are printed guide pages (add 1 for
   PDF page).
